    Phone can't connect on your Wi-Fi (only works over a VPN)?
    1. Use the right address: scan the code marked "use this for phones on your Wi-Fi". The phone must be on the same Wi-Fi as this PC (not mobile data, not a guest network).
    2. Windows Firewall: it often allows the app on VPN networks but not on your Wi-Fi.
    3. Router: turn off "AP isolation" / "client isolation" (or use the main Wi-Fi, not the guest one). That setting stops phones and PCs on the same Wi-Fi from seeing each other, while VPNs still work.
    4. iPhone: Settings → Privacy & Security → Local Network → turn on Safari (or Chrome). Without it, iPhones block local addresses.
    5. Android: turn off any other VPN app, and "Smart network switch" / "Wi-Fi assist" / "Adaptive Wi-Fi" (they can send the phone's traffic over mobile data when the Wi-Fi has no internet).

    Get the apps for phones (and PCs)

    Phones can't use Hamachi, so use Tailscale or ZeroTier for them. Pick one: everyone (host PC and phones) installs the same one and joins the same network. Hamachi friends on PCs keep working at the same time.

    Tailscale (easiest)

    Link not working? Search Tailscale in the Play Store / App Store (by Tailscale Inc.), or use the official install guides: Android (also has a direct APK if you have no Play Store), iPhone, Windows / Mac. Needs Android 8+ / iOS 15+.

    On a PC:
    1. Open tailscale.com/download, pick Windows, run the installer.
    2. Or, in PowerShell: 
      winget install Tailscale.Tailscale
    Then:
    1. Host and friends sign in to the same Tailscale account, or the host invites friends to their network from the Tailscale admin page (Users → Invite).
    2. Once the host PC is connected, a Tailscale address appears in the host section above within a few seconds, with its own QR code - scan it on the phone.
    ZeroTier

    Link not working? Search ZeroTier One in the Play Store / App Store (by ZeroTier, Inc.), or see the Android install page (has a direct APK) and the download page. Needs iOS 12+.

    On a PC:
    1. Open zerotier.com/download, pick Windows, run the installer.
    2. Or, in PowerShell: 
      winget install ZeroTier.ZeroTierOne
    Then:
    1. The host makes a free account at my.zerotier.com, creates a network and shares its 16-character Network ID.
    2. Everyone joins that Network ID in their ZeroTier app; the host ticks "Auth" for each person in the web page.
    3. Once the host PC has joined, a ZeroTier address appears in the host section above within a few seconds - scan its QR code on the phone.

    Phones just need a browser after that - no Watch Party app. If a link doesn't open the right page, search the app name in your phone's store.
